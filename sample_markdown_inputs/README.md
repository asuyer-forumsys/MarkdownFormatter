# Sample markdown test files

These files are intended for testing `markdown_formatter.py`.

- `01-bad-filename-and-h1.md`: H1 does not match file title expectation.
- `02-missing-topics-covered.md`: Missing required `Topics covered` section at top.
- `03-wrapped-paragraphs.md`: Paragraph lines are wrapped mid-paragraph.
- `04-multiple-h1.md`: Contains more than one H1.
- `05-spacing-issues.md`: Missing required blank lines around blocks.
- `Project-management-notes.md`: Intended to already satisfy all requirements.
